# Inter

Source: [Google Fonts Inter](https://github.com/google/fonts/tree/main/ofl/inter).
Downloaded on 2026-10-21 from `ofl/inter/Inter[opsz,wght].ttf`.
The unmodified variable font is bundled locally as `Inter.ttf`; no runtime font download.
License: SIL Open Font License 1.1, included in `OFL.txt` and registered in Flutter's license registry.

Design weights: 400, 500, 600, 700. The bundled font includes English, Latvian
and Spanish coverage, checked with Fontconfig `fc-query`.
